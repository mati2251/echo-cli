# Echo CLI
A simple command-line tool for practicing pronunciation.
It starts recording when you start speaking, stops when you go quiet, and plays your recording back, so you can hear how you actually sound and improve your speaking skills 😊
## Usage
Requires [uv](https://docs.astral.sh/uv/) and PortAudio
```
    just setup
    just run
```
Press **Space** to pause/resume, **Ctrl+C** to quit.
